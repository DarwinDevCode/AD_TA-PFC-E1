# Registro de decisiones de arquitectura

Un ADR (registro de decisión de arquitectura) documenta una decisión que afecta al diseño del proyecto. Registra el contexto, las opciones consideradas, la decisión tomada y sus consecuencias.

Usa la convención de nombres `ADR-NNN-titulo-en-minusculas-con-guiones.md`, con un número de tres dígitos.

| ADR | Decisión | Estado |
| --- | --- | --- |
| ADR-001 | Estilo de arquitectura | Aceptado |
| ADR-002 | Mecanismo de comunicación principal | Aceptado |
