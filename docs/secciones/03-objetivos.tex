\section{Objetivos}
\label{sec:objetivos}

\subsection{Objetivo general}
Diseñar y desarrollar, a lo largo de las cuatro entregas del Proyecto Fin de Curso, una base funcional distribuida para el SGAC de la UTEQ que organice la postulación, selección y seguimiento de ayudantías de cátedra, con trazabilidad de las operaciones e integración simulada de solo lectura con el SGA.
