# Bitácora de trabajo

## Formato de cada entrada

Cada sesión se documenta con los siguientes campos:

- **Fecha:** dd-mm-aaaa.
- **Integrantes presentes:** nombres de quienes participaron.
- **Medio:** presencial o plataforma utilizada, según lo ocurrido.
- **Decisiones tomadas:** acuerdos reales de esa sesión.
- **Problemas resueltos:** dificultades que efectivamente se solucionaron.

Solo se registran hechos confirmados. Los campos sin verificar quedan como **PENDIENTE DE DEFINIR**. Los avances individuales se identifican como tales; no se presentan como reuniones grupales.
